# 计划清单

运行在 Android 10 及以上的本地待办。界面分成「计划」和「设置」两页，右上角和底栏的齿轮进入设置，可在简体中文和 English 之间切换。

计划包含正文、截止时间、状态、提示方式、优先级和次数。正文是文本框，其余选项是下拉按钮，优先级是 1 到 10 的整数滑块。列表按优先级从高到低排列，优先级相同则截止时间更近的在上。

状态默认为进行中。在截止时间之前可以改为 Done 或 Give up。提示可以是弹窗通知，或调用系统时钟的闹钟。时间默认使用系统时区；也可以从手机系统提供的时区里另选一个。次数默认一次，也可以设为每段时间 1 次，间隔最长 30 天：最大单位是天时只精确到小时，最大单位是小时时只精确到分钟，不足 1 小时则精确到秒。

```bash
./gradlew :app:assembleDebug
```
