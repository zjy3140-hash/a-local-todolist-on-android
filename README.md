# 计划清单

![计划清单图标](art/icon.png)

运行在 Android 10 及以上的本地待办。数据只存在这台手机上。界面分成「计划」和「设置」两页，计划页右上角和底栏的齿轮都会进入设置。语言可以在跟随系统、简体中文和 English 之间切换。

## 安装

可直接安装仓库里的安装包：

[`apk/planlist.apk`](apk/planlist.apk)

1. 把这个文件拷到手机。
2. 在文件管理器里点开它。
3. 如果系统询问，允许此来源安装应用。
4. 安装完成后，桌面上的图标是红底上一页纸。

这个包使用 debug 签名，适合自己安装使用。Android 10（API 29）及以上可以安装。

## 计划

点右下角的加号新建。除计划正文是文本框外，其余都是下拉按钮；优先级是 1 到 10 的整数滑块，界面上只显示数字。

| 字段 | 说明 |
| --- | --- |
| 计划 | 要做的事 |
| 截止时间 | 年、月、日、时、分，按当前选定的时区解释 |
| 状态 | 进行中、Done、Give up。新建时是进行中 |
| 提示方式 | 弹窗通知，或闹钟 |
| 优先级 | 1 到 10 的整数。数字大的排在上面 |
| 次数 | 默认一次，也可以设为每段时间 1 次 |

排序固定为：优先级从高到低；优先级相同，截止时间更近的在上。

到达截止时间之前，可以把状态改为 Done 或 Give up。截止时间一到，状态就不能再改。

状态改为 Done 或 Give up 后，计划进入页面下方的失效区，不再提醒。失效区里的计划可以删除，或点「重启」重新选择截止时间。重启后状态回到进行中，按新的截止时间重新开始提醒。

次数为「每段时间 1 次」时，间隔最长 30 天，精度按最大单位收紧：

- 最大单位是天：只精确到小时
- 最大单位是小时：只精确到分钟
- 不足 1 小时：精确到秒

提醒会排到截止时间为止。一次只在截止时提醒；重复则按间隔提醒，并在截止时再提醒一次。进入失效区后，已排上的提醒会取消。

## 设置

- **语言**：跟随系统、简体中文、English。
- **时间**：页面上的时钟来自手机系统时间。默认使用系统时区。需要其他时区时，从手机系统提供的时区列表里选地区和时区。也可以打开系统的日期与时间设置。
- **系统时间权限**：精确闹钟。授予后，提醒才能按系统时钟准点触发。
- **通知权限**：弹窗通知需要它。
- **闹钟全屏**：允许闹钟在锁屏上显示。

## 从源码构建

需要 JDK 17 或更高版本，以及 Android SDK。

```bash
./gradlew :app:assembleDebug
```

生成的安装包在 `app/build/outputs/apk/debug/app-debug.apk`。更新 `apk/planlist.apk` 时，用新包覆盖仓库里的那一份即可。
